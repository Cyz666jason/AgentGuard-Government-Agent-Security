# AgentGuard 复现问题台账（2026-08-13）

## P-20260813-01：JWT篡改测试偶发假阴性

| 字段 | 内容 |
|---|---|
| 发现方式 | 执行 `scripts/run_complete_security.ps1` 完整自动回归 |
| 首次结果 | Keycloak/OIDC 4/5；`tampered_token_blocked=false` |
| 表现 | 对JWT字符串最后一个Base64url字符做替换后，验证器仍接受令牌 |
| 根因 | 最后字符可能仅改变未使用的Base64填充位，不一定改变解码后的RSA签名字节；测试数据实际未必被篡改 |
| 风险 | 会让安全测试不稳定，并可能错误判断JWT验证逻辑存在漏洞 |
| 修复 | 解码签名段，翻转一个真实字节，再进行无填充Base64url编码 |
| 防回归 | 新增 `test_signature_tamper_changes_decoded_bytes` |
| 单项复测 | OIDC单元测试5/5；Keycloak真实E2E 7/7 |
| 完整复测 | 2026-08-14完整脚本退出码0；31/31、55/55、60/60、网络5/5、OIDC7/7、OpenBao10/10、Raft HA 8/8、QEMU11/11、综合检查21/21 |
| 结论 | 已解决 |
